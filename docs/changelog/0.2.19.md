# 0.2.19

This patch tightens Angy's built-in OpenAI suggestion config.

## Highlights

- `suggestionModel` is now a typed object instead of a loose string
- reasoning is validated against the selected OpenAI model
- non-reasoning models no longer receive a `reasoning` block

## Fixes

- stop sending unsupported reasoning settings to GPT-4.1-family models
- align the built-in suggestion request with current documented OpenAI model behavior
- add tests for model config validation and outbound suggestion payload shape
