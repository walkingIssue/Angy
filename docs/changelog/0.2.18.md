# 0.2.18

This release improves Angy's translation workflow stability in dev.

## Highlights

- working catalog preview is safer and clearer
- draft translations no longer write directly into the hot runtime catalog
- locale preview survives reloads more reliably
- stricter catalog path validation prevents writing to the wrong PO files
- helper capture is improved for nested interactive labels

## Fixes

- fixed QA/locale toggle interaction inside the draggable helper
- improved working/base catalog status handling
- reduced false out-of-sync warnings
- stabilized preview flow across reloads and browser engines
